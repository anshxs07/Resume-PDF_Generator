# Resume-PDF_Generator
A simple yet powerful resume builder that allows users to create and download their resumes in PDF format directly from the browser. Built with HTML, CSS, and JavaScript, this project demonstrates dynamic content styling, DOM manipulation, and export-to-PDF functionality without relying on a backend.

FEATURES -:
📑 Predefined, clean resume template
🎨 Fully responsive design
✏️ Live editing of resume content in the browser
📥 One-click export to PDF
⚡ Works offline and is lightweight

TECH STACK Used -:
HTML5 – structure
CSS3 – styling and layout
JavaScript (Vanilla) – interactivity & PDF generation
